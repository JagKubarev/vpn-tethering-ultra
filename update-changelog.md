# v3.16

- «Telegram без VPN» через прокси Opera убран: работал нестабильно и постоянно отваливался. Модуль ведёт себя как в 3.12; исправления 3.13–3.14 (эвристика раздачи, вкладки WebUI) сохранены.
- При первом запуске модуль сам убирает правила, процессы и файлы Opera от прошлых версий, а из файла настроек — ключи OPERA_*.
- Telegram без VPN у операторов, которые закрывают его по IP, теперь не работает — нужен VPN.

# v3.15.1

- Сайты через Opera: берутся только сайты, заблокированные по IP. В 3.15 через Opera могли пойти и соседние сайты на тех же адресах (в том числе нужные сервисы) — исправлено, старый список удаляется.
- Telegram без VPN: если отказали все регионы, модуль берёт любой живой сервер, а не тот, что подсунет Opera (часто нерабочий).
- Если после обновления на компьютере что-то не открывается без VPN — очистите DNS-кэш (`ipconfig /flushdns`).

# v3.15

- Сайты, которые не открыла ни одна стратегия обхода, но открывает Opera, теперь тоже идут через прокси Opera (вкладка «Обход» → «Telegram без VPN» → «Сайты, которые не открывает обход»). Список таких сайтов — там же, лишние можно убрать.
- Телеметрия и реклама через Opera не направляются.

# v3.14

- Telegram без VPN: модуль сам выбирает самый быстрый работающий сервер Opera и переходит на другой, если текущий перестал отвечать. Новый вариант региона — «Самый быстрый» (по умолчанию).
- После выключения VPN сервер проверяется сразу, чтобы Telegram заработал без паузы.
- WebUI: убрана синяя рамка у вкладок после нажатия.

# v3.13

- Telegram без VPN: когда VPN выключен, Telegram на телефоне и на устройствах раздачи работает через бесплатный прокси Opera. Включается во вкладке «Обход» → «Telegram без VPN». Только переписка и файлы, звонки не работают; в белых списках оператора не помогает.
- Исправлено: при подключении телефона к Wi-Fi модуль мог ненадолго принять это подключение за раздачу.
