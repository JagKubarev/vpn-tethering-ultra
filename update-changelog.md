# v3.20.2

- **Google Play не виснет на загрузке** (43%, 99%), YouTube не натыкается на «мёртвые» серверы, и не нужно перезагружать телефон по три раза. Обход сам добавлял в свой список сайты, к которым несколько раз не удалось подключиться, — и туда набрались серверы Google и Play, которым обход только мешал. Теперь Google туда не попадает, а записи старше 30 дней выбрасываются.
- Play больше не обрывается модулем посреди загрузки: он сам выбирает, с какого сервера качать.
- Если загрузка в Play уже зависла — один раз закройте Play (или перезагрузите телефон) после обновления.

# v3.20.1

- **YouTube не висит на задушенных серверах.** Оператор режет часть серверов Google по адресу — они молчат, а через WARP отвечают. Раньше модуль отбивал такие серверы только для обычного HTTPS, и с подделкой QUIC из 3.20.0 YouTube ждал их по QUIC — ролик висел. Теперь отбой и для QUIC: плеер сразу берёт другой сервер.
- Если у вас Google идёт через WARP, задушенные серверы через туннель больше не отбиваются — там они работают.

# v3.20.0

- **QUIC с подделкой вместо закрытия.** Оператор молча режет QUIC к серверам Google, и YouTube сначала ждёт, а потом уходит на обычный HTTPS. Теперь модуль пробивает QUIC обходом: перемотка и загрузка быстрее.
  - Устройства раздачи — по умолчанию (переключатель «QUIC раздачи — с подделкой» на вкладке «Обход»). Банки и Госуслуги — мимо, как и раньше.
  - YouTube и Google Play на телефоне — по переключателю «Подделка вместо закрытия» на вкладке «Сеть». Если стоит AdGuard, модуль пропускает их QUIC мимо него: реклама в YouTube через AdGuard может вернуться.
- **Пропала сеть (метро, лифт) — модуль больше не паникует.** WARP не перебирает и не бракует конфиги, DNS не уходит на оператора и не теряет кэш: всё ждёт возврата сети и продолжает работать как было.
- **Импорт WARP:** файлы `.conf` в выборе файлов Android больше не серые; zip берётся и без расширения.
- **Устройства в раздаче:** трафик теперь накопленный — ↓ и ↑ с момента подключения устройства, а не только по открытым сейчас соединениям.

# v3.19.1

- **WARP подбирает адрес сам.** Сети режут WARP по-разному: одни — часть адресов Cloudflare, другие — порты. Если адрес из конфига молчит, модуль за секунды пробует другие и запоминает рабочий для каждой сети. Раньше на таких сетях все конфиги по очереди уходили в «плохие» — до 7 минут без WARP.
- **Видно, куда выходит WARP:** «Выход: Хельсинки, Финляндия (HEL)» на вкладке WARP. Российские площадки Cloudflare (Москва, Санкт-Петербург), где режут Telegram, модуль обходит; если других нет — работает через них и предупреждает.
- При смене Wi-Fi WARP перезапускается сразу, а не через полминуты.
- **Зашифрованный DNS** работает и в сетях, где обычный DNS наружу закрыт, — раньше там «не отвечали» все серверы разом.
- **Клиенты YouTube без QUIC по умолчанию** (YouTube, Music, ReVanced, Morphe и др.) — включается на вкладке «Сеть». По обычному HTTPS модуль может уводить плеер с медленных серверов.
- В выборе приложений теперь есть и системные (YouTube, Chrome из прошивки); список больше не подтормаживает страницу.
- Chrome мог писать «Нет подключения к интернету» после переподключения мобильной сети — проверки сети Android больше не идут через обход.

# v3.19.0

- **WARP без VPN.** Новая вкладка WARP: бесплатный туннель Cloudflare (AmneziaWG) для того, что не открывает обход, — Telegram и сайты, закрытые по IP или по стране. Работает в режиме «напрямую», когда VPN на телефоне выключен; включается на вкладке WARP.
- Что пускать через WARP: Telegram (по умолчанию; клиенты Telegram на телефоне — целиком), Google (если оператор режет поиск, YouTube и Play), свои домены, отдельные приложения телефона целиком.
- Конфиги: «Создать» регистрирует новый прямо с телефона, импорт `.conf` и zip-экспорта AmneziaVPN, сохранение по одному и все в zip. Если конфиг перестал отвечать, модуль сам переходит на следующий. В файле конфига закрытый ключ — не публикуйте его.
- Приложения, которые фильтрует AdGuard, идут по TCP мимо WARP — исключите их в AdGuard.
- Обход блокировок на ядрах без `connbytes` (часть MTK и старых телефонов): модуль проверяет ядро и включает упрощённый режим, а не молча не работает. YouTube у таких пользователей снова открывается.
- **Устройства в раздаче** (Главная): имя, IP, MAC, число соединений; кнопка «Блок» по MAC. Ушедшие устройства из списка пропадают.
- Если оператор включил белые списки, обход ставится на паузу и не перебирает стратегии впустую; «Проверить сайт» показывает тип блокировки (по IP, по имени, обрыв).
- BBR3 больше не заменяется на BBR.
- WebUI: вкладка «Инструменты» теперь «Сервис», понятнее тексты, вид на маленьких экранах и с крупным шрифтом.

# v3.17

- YouTube и Play Маркет: модуль сбрасывает серверы, которые приняли подключение и молчат, — плеер и загрузки Play быстрее переходят на рабочий сервер, загрузки Play не висят на «Подождите».
- DNS: из запасных серверов убраны Google и Cloudflare — с ними ИИ-сервисы (ChatGPT, Claude, Gemini) писали «недоступно в вашем регионе». В WebUI — кнопка «Сбросить кэш DNS» (Инструменты → Проверки).
- DNS на ноутбуке после выключения VPN больше не отваливается — не нужно переподключаться к точке.
- Если VPN переподключается, раздача несколько секунд ждёт под защитой, а не уходит напрямую с реальным адресом; так же после сбоя самого модуля.
- USB-раздача без VPN больше не выпадает; после удаления модуля возвращается аппаратное ускорение раздачи (если модуль его выключал).
- Много исправлений надёжности по итогам ревью кода: DNS сам возвращается после сбоев, сторож обхода не замолкает после перезагрузки, WebUI не «зависает» на кнопках.
- Если после выключения VPN сайт пишет «недоступно в вашем регионе» — на компьютере выполните `ipconfig /flushdns` (Windows держит адреса, полученные через VPN, до 5 минут).
