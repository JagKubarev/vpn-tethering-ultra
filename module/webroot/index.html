YouTube



  

    
Повтор зависших видеосоединений

      
Зависшее соединение с видеосервером рвётся, и YouTube сразу открывает новое: обход проходит не с каждой попытки. Так же — с запросом без ответа; сам сервер не отключается.

    
  

  

    
Автопроверка после провалов

      
Видеосервер не открылся столько раз за минуту, а видео нигде не идёт, — автопроверка проверит стратегию. Меньше — раньше, но чаще зря.

    
  

  

    
Малое окно для молчащих серверов

      
Видеосервер дважды принял соединение и замолчал — его группе адресов на время ниже уменьшается окно приёма, и фильтр пропускает ответ. Старт на ~0,5 с дольше, до ~5 Мбит/с на соединение. Только nfqws2.

    
  

  

    
Сколько держать малое окно

      
Потом сервер снова пробует полное окно; замолчит дважды — малое вернётся. У некоторых операторов такие серверы молчат днями. Оживают у вас быстрее — поставьте меньше: полная скорость вернётся раньше.

    
  

  

    
YouTube без кэшей оператора

      
Видео грузится с серверов Google, а не с кэшей оператора. Не включайте, если оператор отдаёт видео только с кэшей.

Какие DNS спрашивать

      

    
  

  

    
Серверы DNS (DoH)

      
По порядку: первый — основной, не отвечает — следующий, последним — гео-DoH. ChatGPT, Gemini, Claude и другие сервисы гео-списка спрашиваются у гео-DoH (ниже).

    

  

  

  

    

    

  

  

    
DoH через обход

      
Если оператор режет DoH по имени: соединения с DoH-серверами идут через обход, своей постоянной стратегией. Сломает обход DoH — DNS временно уйдёт к оператору, без обхода гео-блоков.

    
  

  

    
Проверка DNS
Отвечает ли зашифрованный DNS (dnsproxy).

    
  

  

    
Сбросить кэш DNS
Если сайт пишет «недоступно в вашем регионе». На ноутбуке потом ipconfig /flushdns.

    
  









Серверы гео-DoH



  

    
Серверы гео-DoH

      
Для ChatGPT, Gemini, Claude и других сервисов, закрытых для России: отдают адреса своих прокси. По порядку; молчат все — через основной DNS.

  

  

  

    

    

  


  

    
Без гео-DoH — не давать адреса

      
Молчат все гео-DoH — сервисы гео-списка ждут без адреса. Выключено — получат настоящие: из России не откроются, а приложения запомнят их ещё на несколько минут.

    
  

  

    
Свои имена для гео-DoH

      
Домены через пробел, с поддоменами — к гео-списку модуля (около 80 сервисов: ИИ, Spotify, Notion, DeepL, JetBrains …).

WARP: для кого



  

    
Для самого телефона

      
Выбранное в «Что куда идёт» идёт через WARP и в приложениях телефона.

    
  

  

    
Для раздачи

      
Выключено — устройства раздачи ходят без WARP.

    
  

  

    
Весь трафик телефона через WARP

      
Как VPN: все приложения, а не только выбранное в «Что куда идёт». Мимо — система, VPN-клиенты, «Мимо обхода» и список ниже. Банки и Госуслуги увидят зарубежный адрес — добавьте их ниже. Обход для этого трафика не нужен.

    
  

  

    
Весь трафик раздачи через WARP

      
Всё с ноутбука и других устройств, кроме локальной сети. Исключить сайты здесь нельзя: российские сервисы увидят зарубежный адрес.

    
  

  

    
Мимо туннеля

      
Приложения телефона, которые при «весь трафик» (WARP или Opera) идут напрямую. Выбранное в «Что куда идёт» (Telegram и др.) у них по-прежнему через туннель. Если приложение фильтрует AdGuard, исключите его и там: в сеть за него ходит AdGuard.

    

    

  

  

    
Мимо своего сервера

      
У этих приложений то, что идёт в WARP, идёт в обычный WARP, без своего сервера: короче путь и задержка (Telegram, звонки, игры). Остальное — через свой сервер. Только приложения телефона: раздача — через свой сервер.

    

    

    

  

  

    
Telegram мимо своего сервера

      
Сети Telegram — в обычный WARP, и у раздачи: в браузере на ноутбуке и в клиентах там. Быстрее и короче путь. Запасные узлы Telegram (не его сети) у приложений телефона — как выбрано выше.

    
  

  

    
Если выход не работает

      
Что делать с тем, что идёт в WARP, когда свой сервер или сам WARP не отвечает. Блок — приложение увидит «нет сети», а не пойдёт через оператора.

    
  









WARP: подключение



  

    
Как подключаться

      
AmneziaWG — конфиги ниже. MASQUE — как приложение 1.1.1.1: HTTP/3 к Cloudflare, свой аккаунт модуль создаёт сам; часто быстрее и с меньшей задержкой. Если один медленный или не подключается — попробуйте другой. Свой сервер после WARP работает с обоими.

    
  

  

    
Имя для MASQUE

      
Имя сайта в первом пакете подключения: по нему оператор может узнать туннель. Не подключается — попробуйте другое; пусто — имя Cloudflare. По HTTP/2 — всегда имя Cloudflare.

    
    
    
      
    
В подсказках — проверенные имена; можно вписать своё.

    
Аккаунт Cloudflare для MASQUE модуль создал сам. Перестал подключаться совсем — создайте новый.

    

  

  

    
Порт MASQUE

      
Некоторые операторы режут скорость на UDP 443 — тогда помогает другой порт. Не подключается — модуль сам пробует остальные порты и в конце HTTP/2; в плитке видно, на чём работает.

    
  

  

    
MASQUE по TCP (HTTP/2)

      
Если оператор режет UDP к Cloudflare: тот же туннель через TCP (порт — выше), всегда с именем Cloudflare. Задержка обычно больше, чем по UDP.

    
  

  

    
Имя в I1

      
I1 — поддельный QUIC-пакет перед подключением: по имени в нём оператор узнаёт туннель. Если WARP подключается, но работает медленно, — попробуйте другое имя. Меняется только у конфигов Cloudflare, сам конфиг не трогаю.

    
    
Своё имя: модуль соберёт I1 на этом телефоне, со своими DCID и ключами. «DNS-запрос» — I1 в виде запроса к DNS этого имени: имени сайта, по которому режут, в нём нет вовсе. Потом «Применить».

    

  

  

    Конфиги
  
Загрузка…

  

    
    
    
    
  

  

    
    

  

  
  

«Создать» регистрирует конфиг в Cloudflare с телефона; «Из файла» и «Вставить» — .conf из AmneziaVPN или WireGuard (и zip). «Подключить» — сделать основным; замолчит — модуль возьмёт следующий. «Переподключить» — новая сессия.

Не менять сервер

      
Только основной конфиг: замолчал — переподключается он же, на другие не переходит.

Весь трафик телефона через Opera

      
Только TCP: QUIC отбивается (приложения перейдут на TCP), звонки и прочий UDP — напрямую. Мимо — как у WARP, список «Мимо туннеля». Включён и «весь трафик» WARP — главнее WARP; пока он не поднят, подхватит Opera, если в «Если выход не работает» не выбран блок.

    
  

  

    
Весь трафик раздачи через Opera

      
Весь TCP с устройств раздачи, кроме локальной сети; QUIC — отбить, прочий UDP — напрямую.

Сеть



  

    
Переподключить сеть

      
Новая сессия у оператора и обычно новый адрес, без перезагрузки. Связь пропадёт на 5–20 секунд, раздача останется.

    
    

  

  

    
Адаптация TCP к качеству связи

      
Раз в 20 секунд проверяет связь и при потерях или задержке перенастраивает TCP.
