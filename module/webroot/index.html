Защита

Kill-switch
Если VPN упал, раздача не уходит напрямую и твой IP не светится.
Строгий режим
Выбран VPN, а он не подключён — раздача на паузе. Если выключить, раздача сама перейдёт на «напрямую».
Скрыть раздачу от оператора
Телефону TTL 63 и без проверки раздачи у оператора. Другие модули, которые меняют TTL, тогда лишние — модуль подскажет, какие отключить. Устройства с TTL 64 (телефоны, Mac) выходят неотличимо от телефона; Windows — только с TTL 64 у себя.
Не выпускать чужой TTL
Пакеты раздачи с другим TTL (Windows без настройки) не уходят к оператору. Такое устройство останется без интернета напрямую, пока на нём не поставить TTL 64.

Диагностика сети

Что делает оператор
Подмена DNS, обрыв соединений после первых килобайт, белые списки, Telegram. Мимо VPN и обхода, около минуты.

DNS

Свой DNS (DoH)
Зашифрованный DNS через dnsproxy. Выключи, если мешает: DNS будет как в старых версиях.
DoH-сервер
Без VPN. comss и zapret.moe открывают ChatGPT, Gemini, Claude и другие сервисы с гео-блоком; если выбранный молчит, модуль сам переходит на другой.
DNS телефона
Когда VPN выключен, сам телефон тоже спрашивает DNS через DoH-сервер.
DoH для раздачи напрямую
Устройства на раздаче без VPN тоже получают DNS через DoH-сервер.
Instagram и Facebook «как из Европы»
Адреса Meta (Instagram, Facebook, Threads, Messenger) DNS спрашивает у Google так, будто ты в Амстердаме. Приходят европейские серверы, и с обходом DPI они открываются без VPN. Работает там, где DNS идёт через DoH без VPN: раздача напрямую и сам телефон. Проверка — в «Диагностике».
DNS раздачи через VPN

Приложения без QUIC

У этих приложений закрыт HTTP/3 (UDP 443), и они идут по обычному HTTPS. Помогает, когда оператор режет QUIC и часть картинок или видео не грузится.

Обход блокировок

Обход DPI (zapret)
Для трафика без VPN: раздача напрямую и приложения телефона мимо VPN. Помогает с YouTube, Discord, X и сайтами, которые режут по имени. Не помогает, если сайт заблокирован по IP.
Какие сайты
Приложения телефона
Обходить и для приложений, которые идут мимо VPN. Соединения VPN-клиентов не трогаются.
Закрыть QUIC для раздачи
Браузеры на раздаче сразу идут по обычному HTTPS, где обход работает.
YouTube мимо кэша оператора
Отбивать видеосерверы-кэши в сети оператора, чтобы плеер взял сервер Google. Помогает, только если YouTube выдаёт и серверы Google; на YOTA он выдаёт одни кэши, и ролики перестают открываться — там не включай.
Отбивать мёртвые видеосерверы
Если сервер YouTube принял соединение и молчит, его подсеть на 20 минут получает отказ, и плеер сразу берёт другой сервер, а не ждёт ~30 секунд. Список собирается сам.
Сторож обхода
Раз в 15 минут (и сразу, если видео начало застревать) проверяет стратегию этой сети. Сломалась — пробует прежние рабочие, потом быстрый подбор. Нужна «своя стратегия для каждой сети»; при поднятом VPN не работает.
