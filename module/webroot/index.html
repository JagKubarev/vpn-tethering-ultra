YouTube и QUIC



  
Обход блокировок выключен — включается на Главной.

  

    
Пропуск неотвечающих серверов

      
Молчащий видеосервер YouTube отключается на 30 минут, плеер сразу берёт другой.

    
  

  

    
Вести такие серверы через WARP

      
Если сервер отвечает через WARP, видео идёт с него же. Без WARP сервер просто пропускается.

    
  

  

    
Переподключение медленного видео

      
Медленное соединение обрывается, и плеер переходит на быстрый сервер. Быстрых нет — обрывы на время прекращаются.

    
  

  

    
YouTube без кэшей оператора

      
Видео грузится с серверов Google, а не с кэшей оператора. Не включайте, если оператор отдаёт видео только с кэшей.

    
  

  

    
QUIC у YouTube и Google Play

      
QUIC у YouTube (и Music, ReVanced, Morphe, NewPipe) и Google Play закрыт: они идут по HTTPS, где работают пропуск серверов и переподключение видео. Только без VPN.

    
  

  

    
Подделка вместо закрытия

      
QUIC пробивается обходом: видео быстрее перематывается, но пропуск серверов и переподключение по QUIC не работают. AdGuard закрывает QUIC сам, поэтому модуль пускает эти приложения мимо него — реклама в YouTube может вернуться.

    
  

  

    
Без QUIC на раздаче

      
Браузеры раздачи идут по HTTPS, где работает обход. Только без VPN. Пока включена подделка ниже, не действует (если ядро её не умеет — действует закрытие).

    
  

  

    
Подделка QUIC на раздаче

      
QUIC раздачи пробивается обходом: YouTube и Play на устройствах быстрее перематывают.

DNS



  
Зашифрованный DNS выключен — включается на Главной.

  

    
Сервер DNS (DoH)

      
Серверы из первой группы открывают ChatGPT, Gemini и Claude без VPN. Обычные дают настоящие адреса, это для приватности. Не отвечает — по порядку запасные из «Тонкой настройки».

Для раздачи напрямую

DNS раздачи при VPN

      
DNS для устройств раздачи, когда VPN включён.

    
  

  

    
Instagram, Facebook и WhatsApp без VPN

      
Instagram, Facebook, Threads и WhatsApp получают европейские адреса и открываются через обход, без VPN.

    
  

  

    
DoH через обход

      
Если оператор режет DoH-серверы по имени — соединения с ними идут через обход блокировок, своей постоянной стратегией (не той, что у сети). Запасные — тоже через обход, поэтому если обход сломает DoH, DNS временно уйдёт к оператору: интернет будет, но без обхода гео-блоков.

«Создать» регистрирует конфиг в Cloudflare прямо с телефона, импорт — .conf из AmneziaVPN или WireGuard и их zip. «Подключить» делает конфиг основным; перестал отвечать — модуль сам берёт следующий. «Переподключить» — новая сессия того же.
