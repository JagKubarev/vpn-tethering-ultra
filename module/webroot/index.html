YouTube



  
Обход блокировок выключен — включается на Главной.

  

    
Пропуск неотвечающих серверов

      
Видеосерверы YouTube, не отвечающие после соединения, блокируются на 10 минут, и плеер сразу выбирает другой сервер.

    
  

  

    
Переподключение медленного видео

      
Медленные видеосоединения YouTube разрываются, чтобы плеер переподключился к быстрому узлу. Приостанавливается, если быстрых узлов нет.

    
  





Подбор стратегии



  
Поиск рабочей стратегии для текущей сети по списку сайтов. Выполняется в фоне. При сбое стратегии автопроверка обхода запускает его автоматически.

  
  

    
    
    
  

  

  






  Дополнительно
  

    
Обход для приложений телефона

      
Применять обход к приложениям телефона, работающим без VPN. VPN-клиенты не затрагиваются.

    
  

  

    
Без QUIC на раздаче

      
Устройства раздачи переходят с QUIC (HTTP/3) на HTTPS, где работает обход. Действует только для трафика мимо VPN.

    
  

  

    
YouTube без кэшей оператора

      
Блокирует серверы-кэши оператора, чтобы видео загружалось с серверов Google. Не включать, если оператор выдаёт только кэши.

    
  









DNS



  
Зашифрованный DNS выключен — включается на Главной.

  

    
Сервер DNS (DoH)

      
Wlrus, not-a-dns, dagami и comss также открывают сервисы с гео-блокировкой (ChatGPT, Gemini, Claude). При недоступности сервера используется запасной.

    
    
    

  

  

    
Для телефона

      
Зашифрованный DNS для самого телефона, когда VPN выключен.

    
  

  

    
Для раздачи без VPN

      
Зашифрованный DNS для устройств раздачи, когда VPN выключен.

    
  

  

    
Instagram и Facebook без VPN

      
Адреса Instagram, Facebook и Threads запрашиваются с европейским ECS, чтобы открывать их без VPN вместе с обходом блокировок.

    
  





Приложения без QUIC



  
Для выбранных приложений блокируется QUIC (UDP 443), трафик идёт по HTTPS. Помогает, если оператор ограничивает QUIC.
